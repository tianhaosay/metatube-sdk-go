# 映射表种子（deploy/mapping）

本目录提供 `metatube-plus` 的**流派词典种子**，供首次部署使用；运行时映射目录（容器里的 `/data/mapping`）需要可写，两者不要混用。

## 文件

| 文件 | 用途 | 是否预置 |
|---|---|---|
| `mapping_info.xml` | 流派/标签词典（435 条，日文→中文，含「删除」标记） | **必须**：它没有在线同步源，缺了就只剩引擎逐词直译 |
| `genre_dict.json` | 运行时累积的「引擎翻过的标签」缓存 | **不要**预置；由服务自动生成 |

## 首次部署

```bash
mkdir -p ./mapping
cp deploy/mapping/mapping_info.xml ./mapping/
docker compose up -d
```

`mapping_info.xml` 放进运行目录后由运行时维护：服务按文件 mtime 热重载，可以直接在运行目录里手工编辑。

## 词典的格式与更新

- 每一行形如：`<a zh_cn="中文" zh_tw="繁体" jp="日文" keyword=",日文,别名,"/>`
- `zh_cn="删除"` 表示命中该关键词时从输出里删除（例如 `独占配信`、`ハイビジョン`）。
- 更新词典：替换运行目录里的 `mapping_info.xml` 即可；**已刮过的条目要重刮才会套用新词典**（后端有刮削缓存）。
- 新增词条：按上面格式追加，重启或等待热加载后生效。

## 关于 `genre_dict.json`（缓存清理）

- 它是引擎翻译结果的缓存，**不要提交进仓库，也不要预置**。
- 引擎直译质量不稳定，历史上出现过 `ハイビジョン→高视力`、`スレンダー→细长的`、`ギャル→加仑`、`パイズリ→他妈的奶` 这类结果。
- 处理方式：停后端 → 删除运行目录里的 `genre_dict.json` → 启动；之后同类标签会重新按 `mapping_info.xml` 映射，词典没有的才会再次调用引擎。

## 与演员映射的区别

- 演员映射 `mapping_actor.xml` 有在线同步源（`li-peifeng/Jav-Actors-Mapping`），不需要预置，首次启动会自动下载并按天同步。
- 流派词典 `mapping_info.xml` **没有**在线源，所以必须由部署方提供——本目录就是这份种子。
