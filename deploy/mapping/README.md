# 映射表种子（deploy/mapping）

流派词典已经**内置在镜像里**：首次启动时，如果运行目录没有 `mapping_info.xml`，后端会自动写入一份内置词库（435 条），所以**不需要手动复制任何文件**。

## 运行时会发生什么

| 情况 | 行为 |
|---|---|
| 运行目录（`/data/mapping`）里没有 `mapping_info.xml` | 启动时自动写入内置词库，日志打印 `[seed] installed built-in genre mapping table` |
| 运行目录里已有 `mapping_info.xml` | **不覆盖**，以你的文件为准（可以手工编辑，服务按 mtime 热重载） |

内置词库的原文在仓库 `internal/seed/mapping_info.xml`，可直接查阅或照此格式扩写。

## 词典格式与更新

- 每一行形如：`<a zh_cn="中文" zh_tw="繁体" jp="日文" keyword=",日文,别名,"/>`
- `zh_cn="删除"` 表示命中该关键词时从输出里删除（例如 `独占配信`、`ハイビジョン`）。
- 自定义/更新：直接改运行目录里的 `mapping_info.xml` 即可；**已刮过的条目要重刮才会套用新词典**（后端有刮削缓存）。

## 关于 `genre_dict.json`（不要预置）

- 它是「引擎翻过的标签」的缓存，由服务自动生成，**不要提交进仓库、也不要预置**。
- 引擎直译质量不稳定，历史上出现过 `ハイビジョン→高视力`、`スレンダー→细长的`、`ギャル→加仑`、`パイズリ→他妈的奶`。
- 出现劣质译名时：停后端 → 删除运行目录里的 `genre_dict.json` → 启动；之后同类标签会重新按 `mapping_info.xml` 映射，词典没有的才会再调用引擎。

## 与演员映射的区别

- 演员映射 `mapping_actor.xml` 有在线同步源（`li-peifeng/Jav-Actors-Mapping`），首次启动自动下载并按天同步。
- 流派词典 `mapping_info.xml` 没有在线源，所以由镜像内置并在首次启动时落地。
